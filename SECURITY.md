# Segurança

Não publique vulnerabilidades, credenciais, bases de clientes, logs com dados pessoais ou caminhos internos em issues públicas.

Para relatar uma falha de segurança, encaminhe o diagnóstico pelos canais internos da Alpha Software.

Inclua:

- versão do AutoRunner;
- versão do Windows e do SQLBackupAndFTP;
- passos mínimos de reprodução;
- logs sanitizados;
- impacto esperado;
- hash SHA-256 do instalador utilizado.

Nunca anexe:

- senhas;
- arquivos PFX;
- chaves privadas;
- tokens;
- bases de dados de clientes sem autorização e proteção adequadas.
