# Histórico de versões

## 2.2.1

Versão recomendada. Corrige:

- erro de parser do instalador no Windows PowerShell 5.1 ao enumerar hashtables ordenadas;
- congelamento do tutorial após avançar páginas;
- fechamento silencioso do tutorial sem diagnóstico;
- ausência de teste automatizado específico para a navegação.

## 2.2.0

Introduziu o aplicativo instalado, launcher x64 sem console, Setup autoextraível, detecção multicamada, tutorial e manutenção gráfica. Foi substituída pela 2.2.1 devido aos dois defeitos acima.

## 2.1.0 RC

Primeira reestruturação ampla do runner, com seleção explícita, logs, reparo, segurança e QA. Usava launchers BAT/CMD e foi substituída pela linha 2.2.x.

## Política

- versões substituídas permanecem apenas para auditoria e histórico;
- a versão mais recente corrigida deve ser usada em novas instalações;
- uma release só recebe status estável após homologação nativa completa em Windows x64.
