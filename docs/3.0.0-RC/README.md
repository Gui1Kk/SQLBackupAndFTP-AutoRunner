# SQLBackupAndFTP AutoRunner 3.0.0-RC

A 3.0.0-RC implementa o **AutoRunner Control Plane** e transforma o AutoRunner Windows em agente outbound-only para inventário, telemetria e execução remota segura de jobs existentes do SQLBackupAndFTP.
